Virtual Stats Lab

Statistics · Econometrics · Actuarial Science — an interactive simulation bench, like an Arduino circuit simulator but for statistical tests. Turn the knobs, hit RUN, and watch the test statistics, p-values, and charts update live. This is a single downloadable HTML file: save it and reopen it anytime, online or offline, in any browser.

Module 1 — Two-Sample Comparison ready

Generates two random samples from Normal distributions with the settings below, then runs the selected test. Try shrinking the gap between the means, or shrinking n, and watch the p-value climb.

Press RUN to generate samples and run the test.

Module 2 — Regression: Linear vs. Non-Linear Fit ready

Pick a true underlying shape, then pick a fit degree. Watch what happens when you fit a straight line (degree 1) to curved data — and how R² recovers once the fit degree matches the true shape.

Press GENERATE & FIT to create data and fit a curve.

Module 3 — Normality Check ready

Draws a sample from the chosen distribution and runs a simplified D'Agostino-style omnibus normality test (combining skewness and kurtosis into one chi-square statistic).

Press GENERATE & TEST to draw a sample and check normality.

Module 4 — One-Way ANOVA ready

Compares means across 3+ groups simultaneously. Tests if at least one group differs significantly from the others.

Press RUN ANOVA to compare multiple groups.

Module 5 — Chi-Square Tests ready

Tests for independence between categorical variables using a contingency table.

Press RUN CHI-SQUARE to test for independence.

Module 1 — Stationarity (Dickey-Fuller, simplified) ready

Generates a time series as either a random walk (non-stationary) or a mean-reverting AR(1) process (stationary), then runs a simplified single-lag Dickey-Fuller regression: Δy(t) = α + β·y(t−1) + ε. A more negative t-stat than the critical value rejects the unit root.

Press GENERATE & TEST to build a series and check stationarity.

Module 2 — Heteroskedasticity (Breusch-Pagan) ready

Fits y = a + bx, then regresses the squared residuals on x. A significant result means residual variance is NOT constant — the classic "fan shape" that violates an OLS assumption.

Press GENERATE & TEST — canvas shows residuals vs. x (look for a fan shape).

Module 3 — Spurious Regression Demo ready

Generates two completely independent random walks and regresses one on the other. This routinely produces a "significant" result with no real relationship — the reason you must check stationarity (Module 1) before regressing time series.

Press GENERATE & REGRESS to create two unrelated random walks.

Module 1 — Mortality Experience Study ready

Simulates actual deaths as a Poisson process around the table's expected deaths, scaled by a "true" multiplier you control (e.g. 1.15 = 15% worse mortality than the table assumes). Runs a chi-square GOF test and computes the Standardized Mortality Ratio (SMR) with an exact Poisson confidence interval.

Press SIMULATE & TEST to generate an experience study.

Module 2 — Bühlmann Credibility Calculator ready

Enter each group's observed mean claim, variance, and exposure count (n). Computes the Bühlmann credibility factor Z per group and blends each group's own mean with the overall mean accordingly.

Press COMPUTE CREDIBILITY to blend each group's experience with the overall mean.

Module 3 — Chain-Ladder Reserve Simulator ready

Edit the cumulative-loss triangle below (blank/greyed cells are "not yet observed"). Click COMPUTE to derive development factors, project each accident year to ultimate, and total the IBNR reserve.

Press COMPUTE RESERVE to derive development factors and the IBNR reserve.

Module 1 — Vector Autoregression (VAR) ready

Models the joint dynamics of multiple stationary time series. Each variable depends on its own lags and the lags of other variables.

Press SIMULATE & ESTIMATE to fit a VAR model.

Module 2 — Engle-Granger Cointegration ready

Tests if two non-stationary series share a stable long-run relationship. If cointegrated, they move together in the long run.

Press GENERATE & TEST to check for cointegration.

Module 3 — Linear Classifier (Logistic Regression) ready

Demonstrates a simple binary classifier using logistic regression. Two classes with different means — the model learns the decision boundary.

Press GENERATE & CLASSIFY to train a linear classifier.
